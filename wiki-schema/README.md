# wiki-schema

Rules that extend an [LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) schema so the wiki can ingest projects as sources. A vault's own schema links to these rules instead of copying them, so they evolve in one place.

- [`projects.md`](projects.md): the project page type and the "ingest project" flow.
