# One vault per domain, next to its projects

Supersedes ADR 0002. Each domain (e.g. AI projects, physics projects) has its own second-brain vault, placed as a sibling of that domain's projects inside the domain's folder and opened on its own in the note app; each project points to its domain's vault. Lessons no longer link across domains, but domains that share little gain a small, focused vault each, and a vault is never nested inside another folder opened as a vault.
