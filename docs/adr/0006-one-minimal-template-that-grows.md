# One minimal template that grows on demand

There is a single project template, not separate ones for small and large projects: it starts with `AGENTS.md`, `CLAUDE.md`, a docs index and a log, and architecture pages, module pages, a glossary and nested agent files are created only when a project needs them. Nobody knows on day one whether a project will grow, and every empty or generic file costs tokens in every session while teaching the agent nothing.
