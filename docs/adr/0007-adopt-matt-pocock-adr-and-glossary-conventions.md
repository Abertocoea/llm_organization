# Adopt Matt Pocock's ADR and glossary conventions

Projects keep decisions in `docs/adr/` using the short format and the three criteria (hard to reverse, surprising without context, a real trade-off) from [mattpocock/skills](https://github.com/mattpocock/skills), plus an optional `GLOSSARY.md`. Reusing an existing convention instead of inventing one means those skills work on projects built from this template, while the template restates the format so it works without them.
