# Schema names follow the vault's language

The wiki-schema extension is written in English, but an agent applying it translates every name it introduces (folders, page type, frontmatter keys and values, section headings, log type) into the vault's language, the way the vault already names its own things. A vault stays consistent in one language, at the cost of identifiers that differ from vault to vault, so the vault's schema should fix the translated names once.
