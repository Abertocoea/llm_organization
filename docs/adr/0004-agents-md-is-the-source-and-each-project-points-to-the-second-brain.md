# AGENTS.md is the source, and each project carries its own second-brain pointer

Rules live in `AGENTS.md`, read natively by most coding agents, and `CLAUDE.md` contains only `@AGENTS.md`. The pointer to the second brain is written into every project's `AGENTS.md` instead of relying on one file in the parent folder of all projects, because agents differ in whether they read instruction files above the repository root; a parent-folder file is at most a convenience.
