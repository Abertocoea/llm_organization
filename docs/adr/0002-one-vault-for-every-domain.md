# One vault for every domain

All knowledge goes into a single second brain, with domains told apart by folders and frontmatter tags rather than by separate vaults. The value of the wiki is in links across domains (a lesson from a coding project may serve a research one), and links don't cross vaults; token cost stays low anyway because the agent reads the index and then only the relevant pages. Separate vaults remain the answer only for confidential or shared material.
